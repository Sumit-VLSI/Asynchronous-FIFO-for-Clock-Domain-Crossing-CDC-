# Asynchronous-FIFO-for-Clock-Domain-Crossing-CDC-
 Designed parameterized Asynchronous FIFO to safely transfer data between two independent clock domains , Implemented Gray-coded pointers with 2-flip-flop synchronizers to prevent metastability and multi-bit transition issues , Developed dual-clock FIFO memory with separate read/write pointer handlers and robust full/empty detection logic
